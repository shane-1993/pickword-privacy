PickWord 隐私政策

最后更新：2026 年 11 月 17 日 · Last updated: November 17, 2026

一句话

PickWord 是一个离线英语阅读和生词复习工具。应用本身不联网、不收集、不上传你的个人信息。

1. 应用收集什么

不收集任何个人信息。没有账号系统，没有统计分析，没有崩溃上报，没有广告 SDK，也没有把阅读记录发送到服务器的功能。

应用本身不发起网络请求。Microsoft Store 的安装、更新和付费流程由 Microsoft 按其隐私声明处理；如果你通过商店购买，支付信息由 Microsoft 处理，应用不会收到你的银行卡或支付账号信息。

2. 你的数据存在哪里

  • 绿色版：数据保存在程序旁边的 data 文件夹。
  • 安装版（MSIX / Microsoft Store）：数据保存在 Windows 为应用分配的数据目录，通常位于 %LOCALAPPDATA%\Packages\D94CD965.PickWord_09x27zfjhexde\LocalCache\Local\PickWord\data。

这些数据可能包括：文章正文和标题、文件夹、生词和例句、阅读记录、单词/例句笔记、你导入的词典、Markdown 图片、主题和字号设置、面板布局、自动备份和手动备份。

这些文件只在本机使用，不会上传。你可以随时删除数据目录来清空数据；重新打开应用会创建空库。

3. 换机器和卸载

换机器或重装时，请使用「文件 → 备份全部数据…」生成一个 zip（数据库和 Markdown 图片一起打包），再在新机器上使用「从备份恢复…」。

注意：卸载 MSIX 安装包时，Windows 会删除应用数据目录。卸载前请先备份；更新安装包不会删除数据。

4. 第三方组件

应用包含 Qt / PySide6（LGPLv3）、Python（PSF）和内置词典数据 ECDICT（MIT）。这些组件不改变本政策；详细许可文本随应用一起分发，见《第三方许可与声明.md》。

5. 联系方式

隐私问题或数据问题请联系：zjb521@outlook.com

6. 政策更新

如果应用功能变化导致数据处理方式变化，我会更新本页面并修改“最后更新”日期。当前版本没有服务器、没有账号、没有云端同步。

PickWord Privacy Policy

Last updated: November 17, 2026

Summary

PickWord is an offline English reading and vocabulary review app. The app itself does not connect to the internet and does not collect or upload your personal information.

1. What the app collects

No personal information. There is no account system, no analytics, no crash reporting, no advertising SDK, and no feature that sends reading records to a server.

The app itself makes no network requests. Installation, updates and purchases through Microsoft Store are handled by Microsoft under its own privacy statement. If you buy through the Store, payment information is processed by Microsoft; the app does not receive your card or payment account details.

2. Where your data is stored

  • Portable version: data is stored in the data folder next to the program.
  • Installed version (MSIX / Microsoft Store): data is stored in the Windows app data folder, usually %LOCALAPPDATA%\Packages\D94CD965.PickWord_09x27zfjhexde\LocalCache\Local\PickWord\data.

This data may include articles and titles, folders, words and example sentences, reading history, word/sentence notes, imported dictionaries, Markdown images, theme and font settings, panel layout, and automatic/manual backups.

These files stay on your device and are not uploaded. You can delete the data folder at any time to clear your data; the app will create an empty library on the next launch.

3. Moving to another machine and uninstalling

To move to another machine or reinstall, use File → Back up all data to create a zip containing the database and Markdown images, then use Restore from backup on the new machine.

Note: uninstalling the MSIX package deletes the app data folder. Back up before uninstalling. Updating the package does not delete your data.

4. Third-party components

The app includes Qt / PySide6 (LGPLv3), Python (PSF), and the ECDICT dictionary data (MIT). These components do not change this policy. Full license texts are distributed with the app; see 第三方许可与声明.md.

5. Contact

For privacy or data questions: zjb521@outlook.com

6. Changes

If a future feature changes how data is handled, this page will be updated and the “Last updated” date revised. The current version has no server, no account, and no cloud sync.
